## Category 1: Standard Operating Procedures (10 Prompts)

### 1. General SOP Template
```
Write a Standard Operating Procedure for [PROCESS NAME] at [COMPANY]. Include: purpose, scope, responsible parties, prerequisites, step-by-step procedure (numbered), quality checkpoints, exceptions/troubleshooting, revision history section. Format with clear headers. Target audience: [WHO WILL FOLLOW THIS — new hires, team leads, all staff]. Make it so clear that someone with zero context could follow it.
```

### 2. Client Onboarding SOP
```
Write an SOP for onboarding a new client at [BUSINESS TYPE]. Phases: 1) Pre-onboarding (contract signed to kickoff), 2) Kickoff (first meeting agenda), 3) Setup (accounts, access, tools), 4) First deliverable, 5) Check-in cadence. For each phase: actions, responsible person, timeline, tools used, and completion criteria. Include email templates for each touchpoint.
```

### 3. Employee Onboarding SOP
```
Write an employee onboarding SOP for a new [ROLE] at [COMPANY]. Cover: Day 1 (welcome, setup, introductions), Week 1 (training modules, shadowing), Month 1 (milestones, first projects), 90-day review criteria. Include: checklist format, responsible parties (HR, manager, buddy), required tools/access, and cultural orientation items. Make the new hire feel welcomed and productive fast.
```

### 4. Content Publishing SOP
```
Write an SOP for publishing content at [COMPANY/BRAND]. Content types: [BLOG, SOCIAL, EMAIL, VIDEO]. Process: ideation → outline → draft → review → revisions → scheduling → publishing → distribution → performance tracking. Include: tools used at each step, quality checklist before publishing, SEO requirements, brand voice guidelines summary, and approval workflow.
```

### 5. Customer Support SOP
```
Write a customer support SOP for [BUSINESS]. Channels: [EMAIL, CHAT, PHONE, SOCIAL]. Include: response time targets per channel, greeting scripts, escalation matrix (Level 1/2/3), common issues and resolutions (top 5), when to offer refund/discount (decision tree), follow-up procedure, and CSAT survey trigger points. Tone: helpful, empathetic, solution-focused.
```

### 6. Financial Reporting SOP
```
Write an SOP for monthly financial reporting at [BUSINESS TYPE]. Steps: data collection (sources: [LIST]), reconciliation, report generation, review, distribution. Include: specific metrics to track (revenue, expenses, margins, cash flow), report template structure, deadline calendar, who reviews before distribution, and what to flag as abnormal (thresholds).
```

### 7. Inventory Management SOP
```
Write an SOP for inventory management for [BUSINESS TYPE]. Cover: receiving (inspection, logging), storage (organization, labeling), tracking (system: [SYSTEM]), reordering (triggers, minimum stock levels), auditing (frequency, procedure), and handling damaged/expired items. Include: responsible roles, tools used, and KPIs (shrinkage rate, turnover ratio, stockout frequency).
```

### 8. Sales Process SOP
```
Write a sales process SOP for [BUSINESS]. Stages: lead qualification → discovery call → proposal → negotiation → close → handoff. For each stage: specific actions, scripts/templates, tools used, timeline, and advancement criteria. Include: lead scoring framework, disqualification criteria, and CRM data requirements at each stage. Goal: repeatable, measurable process.
```

### 9. Social Media Management SOP
```
Write an SOP for managing social media for [BRAND]. Platforms: [LIST]. Daily tasks: monitoring, engagement, story posting. Weekly tasks: content creation, scheduling, analytics review. Monthly tasks: strategy review, content calendar planning, competitive analysis. Include: brand voice do's and don'ts, crisis response procedure, tool stack, and approval workflow for sensitive topics.
```

### 10. Project Handoff SOP
```
Write an SOP for handing off a completed project to a client or internal team. Include: deliverables checklist, documentation requirements, access/credentials transfer, training session structure (if needed), support transition plan (who they contact post-handoff), feedback collection, and final invoice/sign-off procedure. Goal: clean handoff with zero dropped balls.
```

## Category 2: Meetings & Communication (10 Prompts)

### 11. Meeting Agenda Template
```
Create a meeting agenda for a [MEETING TYPE — weekly standup, project kickoff, quarterly review, 1:1] at [COMPANY]. Duration: [MINUTES]. Attendees: [ROLES]. Include: objectives (max 3), agenda items with time allocations, discussion questions for each item, decision items, action items template, and next steps. Format for pasting into calendar invite.
```

### 12. Meeting Summary Generator
```
Transform these meeting notes into a professional summary: [PASTE RAW NOTES]. Output format: ## Key Decisions (bullet list), ## Action Items (table: Task | Owner | Deadline), ## Discussion Highlights (2-3 sentences per topic), ## Open Questions (who needs to answer, by when), ## Next Meeting (suggested date + agenda items). Under 300 words.
```

### 13. Status Update Email
```
Write a status update email for [PROJECT NAME] to [AUDIENCE — stakeholders, client, team]. Period: [WEEK/MONTH]. Include: executive summary (3 sentences), accomplishments this period (bullet list), upcoming milestones, risks/blockers (with mitigation), metrics/KPIs update, and ask/decision needed. Professional, concise. Under 200 words. Include a visual-friendly format (could paste into Slack too).
```

### 14. Difficult Conversation Script
```
Write a script for having a difficult conversation with [PERSON — employee, client, vendor] about [ISSUE — performance, missed deadline, scope creep, pricing]. Structure: opening (set context, not accusatory), describe the issue factually, explain impact, listen prompt ("I'd like to hear your perspective"), propose solution, agree on next steps. Tone: firm but respectful. Include what NOT to say.
```

### 15. Team Announcement Email
```
Write an internal announcement email about [CHANGE — new hire, policy change, tool migration, org restructure, office move]. From: [YOUR ROLE]. To: [TEAM/DEPARTMENT/COMPANY]. Include: what's changing, why, how it affects them, timeline, what they need to do, who to contact with questions, and positive framing. Transparent, not corporate-speak. Under 200 words.
```

### 16. Quarterly Business Review Outline
```
Create a QBR presentation outline for [BUSINESS/DEPARTMENT] for [Q1-Q4 YEAR]. Sections: 1) Executive summary, 2) Key metrics vs goals (table format), 3) Wins and highlights, 4) Challenges and lessons, 5) Customer/client feedback themes, 6) Competitive landscape update, 7) Next quarter priorities and goals, 8) Resources/budget needed, 9) Q&A. For each section: 2-3 bullet points and suggested data points.
```

### 17. Delegation Email
```
Write an email delegating [TASK/PROJECT] to [PERSON/TEAM]. Include: clear description of what needs to be done, context (why this matters), expected outcome/deliverable, deadline, resources available, decision-making authority they have, check-in points, and how to escalate if stuck. Empowering tone — not micromanaging. Under 150 words.
```

### 18. Client Check-In Email
```
Write a check-in email to [CLIENT NAME] at [COMPANY]. We're [TIMEFRAME] into the project. Include: progress update (2-3 bullets), upcoming milestones, any decisions needed from them, schedule next meeting, and open-ended question about their satisfaction. Professional but warm. Not a report — a relationship touchpoint. Under 150 words.
```

### 19. Feedback Request (360)
```
Write a 360 feedback request email asking [COLLEAGUES/REPORTS/MANAGER] to provide feedback on [EMPLOYEE NAME]. Include: why feedback matters, specific areas to evaluate ([3-5 COMPETENCIES]), rating scale explanation, open-ended questions (3), anonymity assurance, deadline, and link placeholder. Professional, encouraging honesty. Under 150 words.
```

### 20. Cross-Team Collaboration Request
```
Write an email requesting collaboration from [ANOTHER TEAM/DEPARTMENT] for [PROJECT/INITIATIVE]. Include: what you're working on, why their involvement matters, specific ask (what you need from them), time commitment estimate, what's in it for them, proposed meeting to discuss, and deadline for response. Collaborative tone — not a demand. Under 150 words.
```

## Category 3: Business Planning & Strategy (10 Prompts)

### 21. Business Plan Executive Summary
```
Write an executive summary for a business plan. Business: [NAME]. Industry: [INDUSTRY]. Product/service: [WHAT YOU OFFER]. Target market: [WHO]. Revenue model: [HOW YOU MAKE MONEY]. Competitive advantage: [WHAT MAKES YOU DIFFERENT]. Financial projections: [YEAR 1 REVENUE TARGET]. Funding needed: $[AMOUNT] for [PURPOSE]. Under 500 words. Compelling enough that an investor reads the full plan.
```

### 22. SWOT Analysis
```
Conduct a SWOT analysis for [BUSINESS/PRODUCT] in [INDUSTRY/MARKET]. Strengths: identify 5 internal advantages. Weaknesses: identify 5 internal limitations. Opportunities: identify 5 external factors to leverage. Threats: identify 5 external risks. For each item: one sentence explanation. Then provide: 3 strategic recommendations based on the analysis (how to use strengths to capture opportunities, how to mitigate weaknesses against threats).
```

### 23. Competitive Analysis Framework
```
Create a competitive analysis for [MY BUSINESS] against [3-5 COMPETITORS]. Compare: positioning/messaging, pricing, target audience, product features, marketing channels, strengths, weaknesses. Format as a comparison table. Then write: 1) Where we win, 2) Where we're behind, 3) White space opportunities they're all missing, 4) Recommended strategic moves. Use publicly available information.
```

### 24. OKRs (Objectives & Key Results)
```
Write OKRs for [TEAM/COMPANY] for [QUARTER/YEAR]. Context: [BUSINESS GOALS AND CURRENT SITUATION]. Create 3 objectives with 3-4 key results each. Each key result must be: specific, measurable, time-bound, and ambitious but achievable. Include: scoring criteria (0.0-1.0 scale), owner for each KR, and 2-3 initiatives that support each key result.
```

### 25. Pricing Strategy Analysis
```
Analyze and recommend a pricing strategy for [PRODUCT/SERVICE]. Current price: $[PRICE]. Market range: $[LOW]-$[HIGH]. Target customer: [SEGMENT]. Include analysis of: cost-plus pricing, value-based pricing, competitive pricing, and psychological pricing. Recommend: optimal price point with justification, pricing tiers (if applicable), launch pricing vs steady-state pricing, and discount strategy. Include competitor price comparison.
```

### 26. Go-To-Market Strategy
```
Create a go-to-market strategy for launching [NEW PRODUCT/SERVICE]. Target audience: [WHO]. Price: $[PRICE]. Timeline: [LAUNCH DATE]. Include: positioning statement, messaging framework, channel strategy (owned/earned/paid), launch timeline (8 weeks before to 4 weeks after), success metrics/KPIs, budget allocation by channel, and risk mitigation. Actionable, not theoretical.
```

### 27. Annual Goal Setting Framework
```
Create an annual goal-setting framework for [BUSINESS/INDIVIDUAL] for [YEAR]. Categories: revenue, growth, product, team, personal. For each category: 1 big goal, 3 supporting milestones (quarterly), specific actions for Q1 (start immediately), measurement criteria, and potential obstacles with mitigation. Use SMART format. Balance ambition with realism.
```

### 28. Customer Persona Development
```
Create a detailed customer persona for [BUSINESS]. Product/service: [WHAT YOU SELL]. Based on: [DATA YOU HAVE — surveys, analytics, interviews, or assumptions]. Include: demographics (age, income, location, job), psychographics (values, fears, aspirations), behavior patterns (where they spend time online, how they make buying decisions), pain points (top 3), goals (top 3), objections to your product, and preferred communication channels. Give the persona a name and photo description.
```

### 29. Risk Assessment Matrix
```
Create a risk assessment for [PROJECT/BUSINESS INITIATIVE]. Identify 10 potential risks across categories: financial, operational, technical, market, legal/regulatory. For each risk: description, probability (1-5), impact (1-5), risk score (P x I), mitigation strategy, contingency plan, and owner. Present in a table sorted by risk score (highest first). Include an overall risk rating and recommendation.
```

### 30. Partnership Evaluation Framework
```
Create a framework for evaluating potential partnerships for [BUSINESS]. Partnership type: [STRATEGIC/AFFILIATE/JV/DISTRIBUTION]. Evaluation criteria (weighted): strategic alignment (25%), audience overlap (20%), reputation/brand fit (15%), revenue potential (20%), effort required (10%), risk level (10%). Apply this framework to evaluate [POTENTIAL PARTNER]. Score each criterion 1-10. Include: pros, cons, and go/no-go recommendation.
```

## Category 4: Financial & Admin (10 Prompts)

### 31. Invoice Email Template
```
Write a professional invoice email for [SERVICE] provided to [CLIENT NAME]. Invoice #: [NUMBER]. Amount: $[AMOUNT]. Due date: [DATE]. Payment methods: [METHODS]. Include: brief recap of work completed, itemized summary, payment instructions, late payment policy (if applicable), and gratitude. Attach placeholder: "[Invoice_[NUMBER].pdf attached]." Professional, clear, friendly.
```

### 32. Budget Proposal
```
Write a budget proposal for [PROJECT/INITIATIVE] at [COMPANY]. Total requested: $[AMOUNT]. Timeframe: [PERIOD]. Categories: [LIST — personnel, software, marketing, operations]. For each category: line items, costs, justification. Include: executive summary, expected ROI, comparison with alternatives, phased spending option, and approval workflow. Present to: [AUDIENCE — CFO, board, manager].
```

### 33. Expense Report Summary
```
Transform these expense items into a formatted expense report: [PASTE ITEMS — date, vendor, amount, category]. Output: organized table by category, subtotals per category, grand total, notes column for any items needing explanation, policy compliance check (flag items over $[LIMIT]), and executive summary sentence. Ready for submission to [FINANCE/MANAGER].
```

### 34. Contract Summary/Review
```
Summarize the key terms of this contract in plain language: [PASTE KEY SECTIONS OR DESCRIBE]. Include: parties involved, scope of work, compensation/payment terms, timeline, termination clauses, liability/indemnification, IP ownership, confidentiality, and any unusual or concerning clauses to watch out for. Flag anything that needs legal review. I am not a lawyer — include disclaimer. Under 300 words.
```

### 35. Revenue Forecast Model
```
Create a revenue forecast for [BUSINESS] for the next [12/24/36] months. Current MRR: $[AMOUNT]. Growth rate: [PERCENT]%/month. Revenue streams: [LIST]. Include: month-by-month projection table, assumptions clearly stated, best/base/worst case scenarios, key drivers and risks, and breakeven analysis if applicable. Format as a clean table with narrative explanation.
```

### 36. Tax Preparation Checklist
```
Create a tax preparation checklist for a [BUSINESS TYPE — sole proprietor, LLC, S-corp] in [STATE/COUNTRY]. Tax year: [YEAR]. Include: documents to gather (income, expenses, deductions), common deductions for [INDUSTRY], deadlines, estimated tax payment schedule, record-keeping requirements, and items to discuss with accountant. Note: this is a checklist, not tax advice — include disclaimer to consult a CPA.
```

### 37. Cash Flow Management Plan
```
Create a cash flow management plan for [BUSINESS TYPE] with [REVENUE RANGE] monthly revenue. Current challenges: [DESCRIBE — seasonal fluctuations, late payments, high fixed costs]. Include: 13-week cash flow forecast template, strategies to improve collections, expense optimization opportunities, emergency fund recommendation, and early warning indicators of cash flow problems. Practical, not theoretical.
```

### 38. Vendor Comparison Analysis
```
Create a vendor comparison for [SERVICE/TOOL TYPE] for [BUSINESS]. Compare: [VENDOR 1], [VENDOR 2], [VENDOR 3]. Criteria: pricing, features, support quality, scalability, integration capabilities, contract terms, and user reviews summary. Format as a comparison table with a recommendation section. Include: total cost of ownership for [TIMEFRAME], migration considerations, and trial/demo recommendations.
```

### 39. KPI Dashboard Template
```
Design a KPI dashboard for [BUSINESS/DEPARTMENT]. Role viewing: [CEO/MARKETING/SALES/OPERATIONS]. Include [8-12] KPIs organized by category. For each KPI: name, formula/calculation, target, data source, update frequency, and what action to take if above/below target. Format: table with traffic light system (green/yellow/red thresholds). Include a one-page executive summary view.
```

### 40. Profit & Loss Analysis
```
Analyze this P&L data and provide insights: Revenue: $[AMOUNT], COGS: $[AMOUNT], Gross margin: [%], Operating expenses: $[AMOUNT] (breakdown: [CATEGORIES]), Net income: $[AMOUNT]. Compare to: last month, same month last year, industry benchmarks. Identify: top 3 concerns, top 3 opportunities, and 5 specific recommendations to improve profitability. Include margin analysis.
```

## Category 5: Hiring & Team (10 Prompts)

### 41. Job Description
```
Write a job description for a [ROLE] at [COMPANY]. Location: [REMOTE/HYBRID/ONSITE in CITY]. Include: about the company (3 sentences), role overview, responsibilities (8-10 bullets), requirements (must-have vs nice-to-have), compensation range ($[MIN]-$[MAX]), benefits, and application instructions. Tone: [PROFESSIONAL/STARTUP-CASUAL/CORPORATE]. Make it attractive to top talent — sell the opportunity, not just list requirements.
```

### 42. Interview Questions (Role-Specific)
```
Create 15 interview questions for a [ROLE] position. Categories: 5 technical/skill questions (assess ability to do the job), 5 behavioral questions (assess how they work with others), 3 situational questions (assess problem-solving), 2 culture-fit questions. For each question include: what you're evaluating, follow-up probe, and red/green flag answers. Scored on 1-5 rubric.
```

### 43. Offer Letter Email
```
Write an offer letter email for [CANDIDATE NAME] for the [ROLE] position at [COMPANY]. Include: congratulations, role title, start date ([DATE]), compensation ($[SALARY]/year), bonus structure (if applicable), benefits summary, reporting to ([MANAGER NAME]), required documents/pre-employment steps, deadline to accept ([DATE]), and next steps. Exciting tone — this is a celebration. Under 250 words.
```

### 44. Performance Review Template
```
Create a performance review template for a [ROLE] at [COMPANY]. Review period: [PERIOD]. Sections: 1) Key accomplishments (employee fills), 2) Goals achievement (vs last review's targets), 3) Competency ratings (1-5 scale for [5-7 COMPETENCIES]), 4) Strengths, 5) Areas for development, 6) Next period goals (SMART format), 7) Career development discussion, 8) Overall rating. Include self-assessment + manager assessment format.
```

### 45. Team Restructuring Communication
```
Write communications for a team restructuring at [COMPANY]. Change: [DESCRIBE — new reporting structure, team merger, role changes]. Create: 1) All-hands announcement (transparent, factual), 2) Individual email for those directly affected (empathetic, specific to their new role), 3) FAQ document (10 likely questions with answers), 4) Manager talking points (for 1:1s). Honest, not corporate-speak.
```

### 46. Contractor/Freelancer Brief
```
Write a project brief for hiring a freelancer/contractor for [PROJECT]. Include: project overview, objectives, deliverables (specific, measurable), timeline and milestones, budget ($[AMOUNT] or range), required skills/experience, communication expectations (check-ins, tools), revision policy, ownership/IP terms, and how to apply/submit proposal. Clear enough that you get quality proposals, not a flood of questions.
```

### 47. Employee Feedback (Constructive)
```
Write constructive feedback for [EMPLOYEE NAME] regarding [ISSUE — missed deadlines, communication gaps, quality concerns, interpersonal conflict]. Use SBI framework: Situation (when/where), Behavior (what specifically happened), Impact (effect on team/project/client). Then: suggested improvement, support offered, follow-up plan. Tone: caring but direct. This is growth-focused, not punitive. Under 200 words.
```

### 48. Team Charter
```
Create a team charter for the [TEAM NAME] team at [COMPANY]. Include: team purpose/mission (1 sentence), members and roles, goals for [PERIOD], operating norms (communication cadence, decision-making process, conflict resolution), tools and platforms used, success metrics, and review/update schedule. Make it a living document that the team can reference and hold each other accountable to.
```

### 49. Exit Interview Questions
```
Write 12 exit interview questions for an employee leaving [COMPANY]. Cover: reasons for leaving, satisfaction with role/management/culture, what they'd change, feedback on onboarding and development, whether they'd recommend the company, what the company does well, and suggestions for the replacement hire. Include: how to create a safe space for honesty, and how to compile insights into actionable themes.
```

### 50. Remote Work Policy
```
Write a remote work policy for [COMPANY]. Type: [FULLY REMOTE / HYBRID — X days in office / FLEXIBLE]. Include: eligibility, expectations (core hours, availability, response times), equipment/home office stipend ($[AMOUNT]), communication norms, meeting etiquette (cameras, scheduling), performance measurement (output-based, not hours), security requirements, and expense reimbursement. Balanced between flexibility and accountability.
```

## Category 6: Productivity & Automation (10 Prompts)

### 51. Email Template Library
```
Create 10 email templates for [BUSINESS TYPE] covering the most common emails sent. Categories: inquiry response, meeting scheduling, thank you after meeting, project update, delay notification, follow-up (no response), introduction (connecting two people), request for information, apology/service recovery, and holiday/out-of-office. Each: subject line + body under 100 words. Professional, adaptable.
```

### 52. Workflow Automation Design
```
Design a workflow automation for [PROCESS — lead follow-up, invoice sending, onboarding, content publishing]. Tools available: [LIST — Zapier, Make.com, email, CRM, Slack]. Describe: trigger event, each automated step, conditional logic (if/then), human touchpoints (where manual input is needed), error handling, and testing plan. Include a visual flow description. Goal: reduce manual work by [PERCENT]%.
```

### 53. Daily/Weekly Routine Optimizer
```
Optimize my daily/weekly routine as a [ROLE] at [COMPANY TYPE]. Current challenges: [LIST — too many meetings, email overload, context switching, no deep work time]. Energy levels: peak at [TIME], low at [TIME]. Include: ideal daily time blocks, weekly recurring tasks schedule, email batching strategy, meeting-free windows, and shutdown routine. Based on productivity research (time blocking, Pareto principle, energy management).
```

### 54. Decision-Making Framework
```
Create a decision-making framework for [DECISION TYPE — hiring, vendor selection, feature prioritization, investment, go/no-go]. Criteria: [LIST 5-7 CRITERIA with importance weights]. Scoring: 1-10 for each option per criterion. Include: the weighted scoring matrix template, how to gather input from stakeholders, decision thresholds (score above X = proceed), and documentation requirements for the decision rationale.
```

### 55. Process Documentation
```
Document the current process for [PROCESS NAME] at [COMPANY]. I'll describe how it currently works: [DESCRIBE CURRENT PROCESS]. Transform this into: 1) Process map (text-based flowchart), 2) Step-by-step documentation with screenshots placeholders, 3) Bottleneck identification (where delays happen), 4) Improvement recommendations (3-5 specific changes), 5) Time/cost savings estimate from improvements.
```

### 56. Meeting Reduction Strategy
```
I currently have [NUMBER] meetings per week averaging [DURATION]. My role: [ROLE]. Analyze my meeting load and provide: 1) Which meeting types can be eliminated (replaced with async updates), 2) Which can be shortened (with specific format changes), 3) Which are essential (keep as-is), 4) Template for a "Can this be an email?" decision tree, 5) Async alternatives for each eliminated meeting type. Target: reduce meeting time by 40%.
```

### 57. Notion/Project Management Setup
```
Design a [NOTION/ASANA/TRELLO/MONDAY] workspace structure for [TEAM/BUSINESS]. Team size: [NUMBER]. Main workflows: [LIST — project management, CRM, content calendar, task tracking]. Include: workspace hierarchy (spaces/boards/lists), key views needed (kanban, calendar, list, timeline), properties/custom fields, template pages, automation rules, and onboarding guide for team members. Practical, not over-engineered.
```

### 58. SOW (Scope of Work) Template
```
Write a Scope of Work document for [PROJECT] for [CLIENT]. Include: project overview, objectives, deliverables (numbered, specific), timeline with milestones, assumptions, out-of-scope items (explicitly stated), acceptance criteria, change request process, payment schedule tied to milestones, and signatures block. Clear enough to prevent scope creep. Professional format.
```

### 59. Knowledge Base Article
```
Write a knowledge base article explaining [TOPIC/PROCESS] for [AUDIENCE — customers, employees, partners]. Include: title (clear, searchable), summary (2 sentences), step-by-step instructions (with screenshots placeholders), troubleshooting section (3 common issues), related articles (suggest 2-3), and feedback prompt. Written at [READING LEVEL — beginner, intermediate, advanced]. Under 500 words.
```

### 60. Weekly Planning Template
```
Create a weekly planning template for a [ROLE]. Include: week overview (top 3 priorities), daily task sections (Mon-Fri) with categories (must-do, should-do, could-do), habit tracker (3-5 habits), key meetings/deadlines, weekly reflection prompts (what went well, what to improve, what I learned), and next week preview. Format for: [NOTION/GOOGLE DOCS/PRINTED]. Include time estimates for realistic planning.
```
