## Category 1: Ad Copy & Paid Media (15 Prompts)

### 1. Facebook/Instagram Ad — Single Product
```
Write a Facebook ad for [PRODUCT/SERVICE] targeting [AUDIENCE]. Price: $[PRICE]. Include: headline (under 40 chars), primary text (under 125 words), description (under 30 words), and CTA button suggestion. Focus on the transformation, not features. Tone: [TONE — urgent, friendly, professional]. Include one objection-buster in the copy.
```

### 2. Google Search Ad Copy
```
Write 3 responsive search ad variations for [PRODUCT/SERVICE]. Target keyword: "[KEYWORD]". Include for each: 3 headlines (max 30 chars each), 2 descriptions (max 90 chars each). Focus on: [UNIQUE SELLING POINT]. Include numbers, urgency, or social proof in at least one headline per variation.
```

### 3. Retargeting Ad for Cart Abandoners
```
Write a retargeting ad for people who visited [PRODUCT PAGE] but didn't purchase. Product: [PRODUCT] at $[PRICE]. Include: headline that acknowledges they were browsing, body copy that handles the #1 objection ([OBJECTION — price, trust, timing]), and a limited-time offer ([OFFER — 10% off, free shipping, bonus]). Create versions for Facebook and email.
```

### 4. Video Ad Script (30 seconds)
```
Write a 30-second video ad script for [PRODUCT/SERVICE]. Structure: Hook (0-3s): [PAIN POINT question]. Problem (3-10s): Agitate the pain. Solution (10-20s): Introduce [PRODUCT] as the answer. Proof (20-25s): [SOCIAL PROOF — testimonial, stat, result]. CTA (25-30s): [OFFER + urgency]. Include visual directions in brackets.
```

### 5. Carousel Ad (5 slides)
```
Create a 5-slide carousel ad for [PRODUCT/SERVICE]. Target: [AUDIENCE]. Slide 1: Hook headline + eye-catching visual description. Slides 2-4: One benefit per slide with supporting detail. Slide 5: CTA + offer. Each slide: headline (max 5 words) + body (max 15 words). Include visual direction for each slide.
```

### 6. TikTok Ad Script
```
Write a TikTok-style ad script for [PRODUCT/SERVICE] targeting [AGE GROUP]. Length: 15-30 seconds. Must feel organic, not like an ad. Structure: Pattern interrupt opening (first 1s), relatable problem (3s), "I found this thing" discovery moment (5s), quick demo/proof (10s), CTA with urgency (5s). Use casual, conversational language. Include trending sound suggestion.
```

### 7. LinkedIn Sponsored Content
```
Write a LinkedIn sponsored post promoting [SERVICE/PRODUCT] targeting [JOB TITLES]. Include: professional hook that stops scrolling, 2-3 paragraphs of value-driven copy, subtle pitch, and CTA. Tone: authoritative but approachable. Include a relevant statistic. Under 200 words. Suggest an image concept.
```

### 8. YouTube Pre-Roll Ad (15 seconds)
```
Write a 15-second YouTube pre-roll ad for [PRODUCT/SERVICE]. First 5 seconds must hook before "Skip" appears. Structure: "Are you [PAIN POINT]?" (0-2s), quick solution tease (2-8s), offer + CTA (8-15s). Include visual directions. The viewer should understand the value proposition even if they skip at 5 seconds.
```

### 9. Promotional Banner Ad Copy
```
Write copy for a web banner ad promoting [OFFER] for [PRODUCT/SERVICE]. Sizes needed: leaderboard (728x90), medium rectangle (300x250), and mobile (320x50). For each size provide: headline, subtext, and CTA button text. Shorter for smaller sizes. Include urgency element: [DEADLINE or SCARCITY].
```

### 10. A/B Test Variations
```
I'm running ads for [PRODUCT/SERVICE] targeting [AUDIENCE]. Current ad headline: "[CURRENT HEADLINE]". Current CTA: "[CURRENT CTA]". Generate 5 alternative headlines and 3 alternative CTAs to A/B test against the originals. For each variation, explain the psychological trigger being used (urgency, curiosity, social proof, fear of missing out, etc.).
```

### 11. Competitor Comparison Ad
```
Write an ad that positions [MY PRODUCT] against [COMPETITOR] without naming them directly. Use phrases like "other solutions" or "traditional approaches." Highlight 3 specific advantages of my product: [ADVANTAGE 1], [ADVANTAGE 2], [ADVANTAGE 3]. Tone: confident, not aggressive. Include a "switch and save" offer.
```

### 12. Seasonal/Holiday Ad Campaign
```
Create a [HOLIDAY/SEASON] ad campaign for [PRODUCT/SERVICE]. Include: campaign theme/tagline, 3 ad variations (different angles), email subject line, social media caption, and SMS message. Holiday: [HOLIDAY]. Offer: [DISCOUNT/BUNDLE]. Timeframe: [START DATE] to [END DATE]. Make it feel festive but not cheesy.

### 13. Lookalike Audience Ad
```

The ad should: qualify the audience in the first line ("If you're a [ROLE] who [DOES X]..."), present the offer, and include a low-friction CTA (free trial, quiz, guide — not "buy now").

Create: 1) A quote-style ad with the testimonial as the centerpiece, 2) A story-style ad expanding on the customer's journey, 3) A "results" ad focusing on the specific outcome mentioned.
