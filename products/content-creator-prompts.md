## Category 1: Blog Posts & Articles (16 Prompts)

### 1. SEO Blog Post Outline
```
Create a detailed blog post outline for the keyword "[TARGET KEYWORD]." Search intent: [INFORMATIONAL/COMMERCIAL/TRANSACTIONAL]. Include: SEO title (under 60 chars), meta description (under 155 chars), H1, 5-7 H2 sections with 2-3 H3 subsections each, word count target, internal link suggestions (2-3), and a featured snippet-optimized section. Competitor URLs doing well: [LIST 2-3 if available].
```

### 2. Full Blog Post Draft
```
Write a [WORD COUNT]-word blog post about "[TOPIC]." Target keyword: "[KEYWORD]." Audience: [WHO]. Tone: [CONVERSATIONAL/PROFESSIONAL/CASUAL]. Structure: compelling intro (hook + promise), [NUMBER] main sections with actionable advice, real examples, and a conclusion with clear CTA. Include: transition sentences between sections, one personal anecdote or story, and a summary box. Optimize for SEO without sounding robotic.
```

### 3. Listicle Post
```
Write a listicle blog post: "[NUMBER] [TOPIC] for [AUDIENCE]." Example: "15 Time-Saving Tools for Freelancers." For each item include: name, one-sentence description, why it's on the list, best for (use case), price (if applicable). Add an intro explaining why this list matters and a conclusion with your #1 pick. SEO keyword: "[KEYWORD]." Under [WORD COUNT] words.
```

### 4. How-To Guide
```
Write a comprehensive how-to guide: "How to [ACHIEVE RESULT]." Target: [AUDIENCE with SKILL LEVEL]. Include: what they'll need (prerequisites, tools), step-by-step instructions (numbered, clear), pro tips (at least 3), common mistakes to avoid (at least 3), expected timeline, and troubleshooting section. Add a "Quick Start" summary box at the top for skimmers. SEO keyword: "[KEYWORD]."
```

### 5. Comparison Post
```
Write a comparison post: "[OPTION A] vs [OPTION B]: Which is Better for [USE CASE]?" Include: overview of each, feature-by-feature comparison (table format), pricing comparison, pros/cons of each, who each is best for, and your recommendation. Be fair and balanced — don't trash either option. Include an "If you're [TYPE], choose [X]" section. SEO keyword: "[KEYWORD]."
```

### 6. Case Study Blog Post
```
Transform this result into a case study blog post: [CLIENT/COMPANY] went from [BEFORE] to [AFTER] in [TIMEFRAME] using [METHOD/PRODUCT]. Structure: The Challenge (paint the problem), The Solution (what was done, step by step), The Results (specific metrics), Key Takeaways (3-5 lessons readers can apply). Include quotes (real or placeholder), data visuals description, and CTA to achieve similar results.
```

### 7. Pillar/Ultimate Guide
```
Create an outline for an ultimate guide: "The Complete Guide to [TOPIC]." This is a 3000+ word pillar page targeting "[KEYWORD]." Include: table of contents, 8-10 major sections, each with 3-4 subsections, FAQ section (10 questions), resource links section, downloadable checklist CTA, and internal linking strategy (what supporting posts to create). This should be THE definitive resource on this topic.
```

### 8. Product Review Post
```
Write a product review for [PRODUCT NAME] in [CATEGORY]. Based on: [YOUR EXPERIENCE or RESEARCH]. Include: product overview, features breakdown, setup/getting started, real usage experience (what's great, what's not), pricing analysis, comparison with alternatives (top 2), who it's for and who should skip it, final rating (X/10), and affiliate disclaimer. Honest, helpful, not salesy.
```

### 9. Roundup/Expert Post
```
Write a roundup post: "[NUMBER] Experts Share Their Best [TOPIC] Tips." Create [NUMBER] fictional (but realistic) expert contributions. Each entry: expert name + title + company, their tip (2-3 sentences), and a key takeaway. Include: intro explaining why you gathered these insights, a summary of common themes, and CTA. This format builds authority and is highly shareable.
```

### 10. Trending Topic Response
```
Write a timely blog post responding to [TRENDING TOPIC/NEWS] in [INDUSTRY]. Angle: [YOUR UNIQUE PERSPECTIVE]. Include: what happened (brief recap), why it matters for [AUDIENCE], your analysis/opinion (supported by evidence), what to do about it (actionable advice), and prediction for what happens next. Quick-turnaround format — under 800 words. Optimize for [KEYWORD] while it's trending.
```

### 11. Guest Post Pitch + Draft
```
Write a guest post pitch for [TARGET PUBLICATION] about [TOPIC]. Include: 1) Pitch email (personalized, references their content, proposes 3 topic ideas), 2) Full draft of the best topic idea ([WORD COUNT] words), 3) Author bio (50 words), 4) Social share messages (2-3). The post should provide unique value their audience doesn't get elsewhere. Follow their style guide: [DESCRIBE or "standard blog format"].
```

### 12. FAQ/Resource Page
```
Create a comprehensive FAQ page for [BUSINESS/PRODUCT] with [NUMBER] questions. Categories: Getting Started, Pricing, Features, Troubleshooting, Account/Billing. Each answer: 2-4 sentences, direct and helpful. Include: schema markup suggestion (FAQ structured data), search-optimized question phrasing, and internal links where relevant. Goal: reduce support tickets and improve SEO.
```

### 13. Content Refresh/Update
```
I need to update this existing blog post: "[TITLE]" (URL: [URL], published [DATE]). Current word count: [WORDS]. It currently ranks [POSITION] for "[KEYWORD]." Suggest: sections to add/expand, outdated information to update, new statistics/data to include, internal links to add, title/meta updates, new images/media to add, and additional keywords to target. Goal: improve ranking from [CURRENT] to top 3.
```

### 14. Personal Story / Opinion Post
```
Write a personal/opinion blog post about [TOPIC] based on my experience: [DESCRIBE YOUR EXPERIENCE OR STANCE]. Structure: Hook (bold opening statement or question), My Story (what happened, what I learned), The Lesson (universal takeaway), How to Apply This (practical advice for readers), Your Turn (invitation for readers to share). Vulnerable, authentic tone. Under [WORD COUNT] words.
```

### 15. Data-Driven Post
```
Write a data-driven blog post: "[HEADLINE with STATISTIC]." Example: "73% of Marketers Are Wasting Budget — Here's Why." Data points I have: [LIST YOUR DATA/STATS]. For each data point: contextualize it, explain why it matters, and provide an actionable insight. Include: data visualization descriptions (chart types), methodology note, sources, and infographic-worthy summary. Authoritative, not dry.
```

### 16. Content Repurposing Plan
```
I have this piece of content: [DESCRIBE — blog post, video, podcast episode, presentation]. Transform it into: 1) 5 social media posts (different angles), 2) An email newsletter, 3) An infographic outline, 4) A short video script (60 seconds), 5) 3 tweet/thread ideas, 6) A LinkedIn article version, 7) A podcast talking points version. For each: provide the adapted content, not just a description of what to do.
```

## Category 2: Video Scripts (16 Prompts)

### 17. YouTube Video Script (Full)
```
Write a [LENGTH]-minute YouTube video script about "[TOPIC]." Target audience: [WHO]. Include: hook (first 5 seconds — question, bold claim, or visual tease), intro (who you are, what they'll learn), [NUMBER] main sections with transitions, examples/stories for each point, engagement prompts ("comment below if..."), mid-roll CTA (like/subscribe), and strong outro with next video tease. Script style: [TELEPROMPTER / BULLET POINTS / CONVERSATIONAL].
```

### 18. YouTube Shorts / TikTok Script
```
Write [NUMBER] short-form video scripts (30-60 seconds each) about [TOPIC] for [PLATFORM]. Each script: hook (first 1 second — must stop the scroll), content delivery (fast-paced, one point per script), CTA (follow, save, or share). Include: text overlay suggestions, visual directions, and trending format recommendation. Target: [AUDIENCE]. Tone: [EDUCATIONAL / ENTERTAINING / INSPIRING].
```

### 19. Tutorial/How-To Video Script
```
Write a tutorial video script: "How to [DO SOMETHING] in [TIMEFRAME/STEPS]." Software/tool: [IF APPLICABLE]. Include: intro (what they'll achieve), prerequisites check, step-by-step walkthrough with screen recording directions, tips at each step, common mistakes callout, final result showcase, and "What to do next" recommendation. Beginner-friendly language. Under [LENGTH] minutes.
```

### 20. Product Demo Video Script
```
Write a product demo video script for [PRODUCT/SERVICE]. Length: [MINUTES]. Structure: problem statement (why this exists), product introduction, feature walkthrough (top [NUMBER] features), real use case demonstration, pricing mention, social proof moment, and CTA (free trial/buy/sign up). Tone: enthusiastic but not infomercial. Focus on benefits, show features in context of solving problems.
```

### 21. Talking Head Video Script
```
Write a talking-head video script about [TOPIC]. This is a personal, direct-to-camera style. Length: [MINUTES]. Structure: strong opinion or insight opening, 3 key points with personal anecdotes, counterargument acknowledgment ("Now, some people might say..."), practical takeaway, and authentic sign-off. Should feel like a conversation, not a lecture. Include pauses and emphasis markers.
```

### 22. Video Sales Letter (VSL)
```
Write a Video Sales Letter script for [PRODUCT/SERVICE] at $[PRICE]. Length: [5-15 MINUTES]. Structure: hook (problem/pain), agitate (make it worse), story (how you discovered the solution), solution reveal, benefits (not features), social proof, what's included (value stack), price reveal with anchor, guarantee, bonuses, urgency, final CTA repeated 3 times. Persuasive but not manipulative.
```

### 23. Course/Lesson Video Script
```
Write a video lesson script for Module [NUMBER]: "[LESSON TITLE]" in a course about [COURSE TOPIC]. Length: [MINUTES]. Include: lesson objective (what they'll be able to do after), recap of previous lesson, new content (3-5 teaching points), examples for each point, practice exercise, common questions/FAQ, and preview of next lesson. Educational, encouraging tone. Include slides/visual descriptions.
```

### 24. Interview Questions for Guest
```
Write [NUMBER] interview questions for [GUEST NAME], who is a [THEIR EXPERTISE/ROLE]. Platform: [PODCAST/YOUTUBE/LIVE]. Include: 2 warm-up questions (easy, build rapport), [NUMBER] deep-dive questions (their expertise, unique insights), 2 personal/story questions (memorable moments, lessons), 1 contrarian/spicy question (respectfully challenging), and 1 closing question (advice or prediction). For each: follow-up probe.
```

### 25. Video Intro/Outro Script
```
Write an intro and outro script for my [YOUTUBE CHANNEL / PODCAST / VIDEO SERIES] called "[NAME]." Niche: [NICHE]. Intro (15-20 seconds): hook format, channel value proposition, subscribe CTA. Outro (20-30 seconds): recap, next video tease, engagement CTA (comment, share), subscribe reminder, and sign-off catchphrase. Create 3 variations to rotate. Include music/sound effect suggestions.
```

### 26. Live Stream Outline
```
Create a live stream outline for a [DURATION]-minute session about [TOPIC]. Platform: [YOUTUBE/TWITCH/INSTAGRAM/LINKEDIN]. Include: pre-stream checklist (tech, promotion), opening (welcome + topic intro), content segments (3-4 with time allocations), Q&A breaks, engagement prompts (polls, questions), transition between segments, and closing (next stream tease, CTA). Include chat moderation tips.
```

### 27. Documentary-Style Video Script
```
Write a documentary-style video script about [TOPIC/STORY]. Length: [MINUTES]. Structure: cold open (dramatic moment or question), title sequence, Act 1 (setup/context), Act 2 (rising action/exploration), Act 3 (climax/revelation), denouement (reflection), and closing thought. Include: narration text, interview clip placeholders, b-roll descriptions, music mood notes, and text overlay suggestions. Cinematic tone.
```

### 28. Explainer Video Script (90 seconds)
```
Write a 90-second explainer video script for [PRODUCT/SERVICE/CONCEPT]. Style: [ANIMATED/LIVE-ACTION/MIXED]. Structure: "Meet [CHARACTER] who has [PROBLEM]" → "They tried [OLD SOLUTIONS] but..." → "Then they discovered [YOUR SOLUTION]" → "Now they [POSITIVE OUTCOME]" → CTA. Include: voiceover text, visual scene descriptions, and on-screen text callouts. Simple language. One clear message.
```

### 29. Reaction/Commentary Video Script
```
Write a reaction/commentary video script responding to [CONTENT — article, video, trend, news]. My angle: [YOUR PERSPECTIVE]. Structure: context (what I'm reacting to), initial reaction (genuine, entertaining), deeper analysis (3 key points), what most people get wrong about this, my conclusion/opinion, and engagement prompt (ask viewers their take). Personality-driven, not just recapping.
```

### 30. B-Roll Shot List
```
Create a b-roll shot list for a video about [TOPIC]. Video type: [TUTORIAL/VLOG/PROMOTIONAL/DOCUMENTARY]. Generate [NUMBER] shot descriptions organized by: establishing shots (setting the scene), detail shots (close-ups), action shots (doing the thing), reaction shots, and atmospheric shots. For each: description, estimated duration, and what it supports in the narrative. Include equipment suggestions.
```

### 31. YouTube Title + Thumbnail Concepts
```
Generate 10 YouTube title and thumbnail concept pairs for a video about [TOPIC]. For each: title (under 60 chars, curiosity or benefit-driven), thumbnail description (what text, what expression, what visual, what colors). Apply principles: contrast, emotion, simplicity, curiosity gap. Include: A/B test pairs (2 titles for the same video to test). Target audience: [WHO].
```

### 32. Video Series Blueprint
```
Design a [NUMBER]-part video series about [BROAD TOPIC]. For each episode: title, key question it answers, what the viewer learns, hook, and how it connects to the next episode. Include: series trailer script (60 seconds), release schedule recommendation, cross-promotion strategy between episodes, and series-level CTA (what they should do after watching all episodes). Build dependency — each episode makes the next one a must-watch.
```

## Category 3: Newsletter & Email Content (16 Prompts)

### 33. Newsletter Issue Template
```
Write a newsletter issue for [NEWSLETTER NAME] about [NICHE]. Target: [AUDIENCE]. Structure: subject line (3 options), preview text, personal opener (2-3 sentences), main story/insight ([TOPIC] — 200 words), curated links (3-5 with one-line commentary each), tool/resource spotlight, CTA (product, survey, or engagement), and P.S. line. Tone: [FRIENDLY/WITTY/PROFESSIONAL]. Under 500 words total.
```

### 34. Newsletter Welcome Sequence
```
Write a 3-email welcome sequence for new subscribers to [NEWSLETTER]. Email 1 (immediate): Welcome + what to expect + best content link. Email 2 (Day 2): Your story/mission + invite to reply. Email 3 (Day 4): "Here's what most people do next..." + CTA to [PRODUCT/COMMUNITY/RESOURCE]. Each: subject line, body under 150 words. Goal: build relationship and set engagement habits.
```

### 35. Content Curation Newsletter
```
Write a curated newsletter with [NUMBER] items about [TOPIC/INDUSTRY] for [AUDIENCE]. For each item: source/link placeholder, headline, 2-sentence summary of why it matters, and your hot take (1 sentence). Categories: [LIST 3-4 categories]. Include: editorial intro (your take on the week's theme), and a "If you only read one thing" recommendation. Make curation feel opinionated, not just a link dump.
```

### 36. Sponsor/Ad Integration Copy
```
Write a native sponsor integration for a newsletter about [NICHE]. Sponsor: [BRAND/PRODUCT]. What they offer: [DESCRIPTION]. Include: 3 integration styles: 1) "Today's issue is brought to you by..." (classic), 2) Mid-content native mention (woven into the content), 3) "Tool I've been using" personal recommendation style. Each: under 75 words. Must feel natural to readers, not disruptive.
```

### 37. Subscriber Milestone Email
```
Write an email celebrating a subscriber milestone for [NEWSLETTER]. Milestone: [NUMBER] subscribers. Include: genuine gratitude, one meaningful stat ("You've read [X] issues"), behind-the-scenes insight (what creating this newsletter means to you), what's coming next (exciting tease), special offer for existing subscribers, and referral ask. Authentic, not boastful. Under 200 words.
```

### 38. Newsletter Relaunch Email
```
Write an email relaunching/revamping [NEWSLETTER]. Changes: [WHAT'S NEW — format, frequency, topics, name]. Include: acknowledge the gap/change, explain why (honest), what they can expect going forward, re-opt-in CTA (give them choice to stay), and a sample of the new format. Humble, excited, respectful of their inbox. Under 200 words.
```

### 39. Seasonal/Themed Newsletter
```
Write a [HOLIDAY/SEASON]-themed newsletter issue for [NICHE]. Include: themed subject line, seasonal hook, [NUMBER] tips/ideas related to [TOPIC + SEASON], gift guide or resource list (if relevant), year-in-review or year-ahead element, personal reflection, and seasonal offer/CTA. Festive but not generic — tie the theme to your specific niche authentically.
```

### 40. Newsletter Growth Strategy
```
Design a newsletter growth strategy for [NEWSLETTER NAME] in [NICHE]. Current subscribers: [NUMBER]. Goal: [TARGET] in [TIMEFRAME]. Provide: 10 specific growth tactics (ranked by effort vs impact), sample social media posts to promote the newsletter (3), referral program structure, lead magnet ideas (3), cross-promotion partnership template, and metrics to track weekly. Actionable, not theoretical.
```

### 41. Deep Dive Issue
```
Write a deep-dive newsletter issue about [SPECIFIC TOPIC]. Length: [WORD COUNT — 1000-2000]. Structure: the hook (why this matters right now), background (quick context), the analysis (your unique angle, 3-5 key points), data/evidence, implications (what this means for the reader), action items (what to do), and resources for further reading. This should be the best thing they read all week.
```

### 42. Q&A / Mailbag Issue
```
Write a Q&A newsletter issue answering reader questions about [NICHE]. Questions to answer: [LIST 5-7 QUESTIONS or "generate common questions"]. For each: reader's question (can be paraphrased), your answer (concise but thorough, 50-100 words), and a resource link if relevant. Include: intro asking for more questions (reply to this email), and a "Question of the Month" feature with a longer answer.
```

### 43. Partnership Newsletter Swap
```
Write newsletter swap content for a cross-promotion with [PARTNER NEWSLETTER]. Their niche: [THEIR NICHE]. My newsletter: [MY NEWSLETTER] about [MY NICHE]. Create: 1) Blurb about my newsletter for their audience (under 100 words + CTA), 2) Blurb about their newsletter for my audience (under 100 words + CTA), 3) Email to propose the swap (professional, shows mutual benefit). Make both blurbs compelling to the other's audience.
```

### 44. Prediction / Trend Report Issue
```
Write a trend prediction newsletter issue: "[NUMBER] [INDUSTRY/NICHE] Predictions for [YEAR/QUARTER]." For each prediction: the trend (one sentence), why it's happening (context), evidence (data or signals), what to do about it (action item), and confidence level (high/medium/low). Include: intro framing why predictions matter, bold contrarian prediction, and invitation for readers to share their own.
```

### 45. Behind-the-Scenes Issue
```
Write a behind-the-scenes newsletter issue about [WHAT — how I create content, my tech stack, a recent project, a failure I learned from]. Structure: casual intro, the story (transparent, specific details readers don't usually see), numbers/data (revenue, growth, costs — be as transparent as comfortable), lessons learned, and what I'd do differently. This builds trust through vulnerability. Include 1 resource/tool recommendation.
```

### 46. Annual Review Issue
```
Write an annual review newsletter issue for [YEAR]. Include: top [NUMBER] highlights/wins, biggest failure/lesson, most popular content (top 3 issues), subscriber growth story, goals for next year, thank you to readers, and "Best of [YEAR]" curated list. Format: scannable, uses numbers and bold text. Reflective but forward-looking. Under 600 words.
```

### 47. Reader Challenge Issue
```
Write a newsletter issue launching a [DURATION] challenge for readers. Challenge: [DESCRIBE — 7-day writing challenge, 30-day fitness challenge, 5-day email cleanup]. Include: what it is, why it matters, daily/weekly structure, how to participate, community element (hashtag, reply thread), prize/incentive (if any), and Day 1 instructions. Make it feel achievable and exciting, not overwhelming.
```

### 48. Monetization Strategy Issue
```
Write a newsletter issue about [MONETIZATION TOPIC — going paid, launching a product, offering consulting] that naturally pitches [YOUR OFFER]. Instead of a hard sell, make it a valuable content piece about [TOPIC] that demonstrates your expertise, with a natural transition to your offer. Structure: valuable content (80%), soft pitch (20%). The reader should feel they got value even if they don't buy.
```

Write a podcast episode description for: "[EPISODE TITLE]." Guest: [NAME, if applicable]. Under 200 words. Optimized for podcast app search.

### 51. Podcast Show Notes

## Category 5: Social Media Content Creation (16 Prompts)

### 65. 30-Day Content Calendar
```
Create a 30-day content calendar for [PLATFORM] in [NICHE]. Audience: [WHO]. Include for each day: content type (educational, entertaining, personal, promotional), topic, hook/first line, format (image, carousel, video, text), and posting time. Mix: 50% educational, 20% entertaining, 15% personal, 15% promotional. Include: content pillars (4-5 recurring themes), and one viral-attempt post per week.
```

### 66. Instagram Carousel (10 slides)
```
Write a 10-slide Instagram carousel about "[TOPIC]." Target: [AUDIENCE]. Slide 1: Hook headline (make them swipe). Slides 2-9: One point per slide (concise text, each builds on the last). Slide 10: CTA + save prompt. For each slide: text content (max 3 lines), visual description/layout suggestion, and design notes. Include: caption, 20 hashtags, and alt text for accessibility.
```

### 67. Viral Content Framework
```
Create [NUMBER] content pieces designed to go viral in [NICHE]. For each: hook (first line that stops scrolling), content body (the value), CTA (engagement driver). Apply viral frameworks: 1) Counterintuitive insight, 2) Transformation story, 3) List of surprising facts, 4) Controversial opinion, 5) Behind-the-scenes reveal. Platform: [PLATFORM]. Include: optimal posting time, hashtag strategy, and engagement bait question.
```

### 68. Content Pillar Strategy
```
Design a content pillar strategy for [BRAND/CREATOR] on [PLATFORM]. Niche: [NICHE]. Create 5 content pillars with: pillar name, description, why the audience cares, 10 specific post ideas per pillar, best format for each pillar, and posting frequency. Then create: a weekly schedule rotating through pillars, and a "content engine" system for never running out of ideas (inspiration sources, repurposing flows).
```
